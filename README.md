# 🚀 Professional Portfolio - Gowtham Sankar G

Welcome to my professional portfolio! This is a modern, high-performance web application built with **Angular 20**, designed to showcase my skills, experience, and projects as a Lead Software Developer.

## ✨ Features

- **Rich Aesthetics**: Vibrant design with dark/light mode support.
- **Micro-Animations**: Smooth transitions and floating tech icons for an engaging experience.
- **Glassmorphism**: Modern UI components using Gaussian blur and subtle borders.
- **Optimized Performance**: High Lighthouse scores for LCP, FCP, and CLS.
- **Responsive Design**: Fully functional across desktop, tablet, and mobile (orientation-aware).
- **SEO Ready**: Semantic HTML5 and meta tags for better search visibility.

## 🛠️ Tech Stack

- **Framework**: [Angular 20](https://angular.io/)
- **Logic**: TypeScript
- **Styling**: Vanilla CSS (Custom Design System)
- **Icons**: Font Awesome 6
- **Deployment**: GitHub Pages

## 🚀 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and [Angular CLI](https://github.com/angular/angular-cli) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/GouthamGuna/portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Run the following command to start a local development server:
```bash
npm run start
```
Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## 📦 Build & Deployment

### Build for Production

To create an optimized production build:
```bash
npm run build
```
The build artifacts will be stored in the `dist/portfolio/browser` directory.

### Manual Deployment to GitHub Pages

The portfolio is deployed to the `in` repository on the `angular-portfolio` branch.

1. Build the project.
2. Copy the contents of `dist/portfolio/browser` to your deployment directory.
3. Update `base-href` in `index.html` to `/in/`.
4. Create a `404.html` (copy of `index.html`) for SPA routing support.
5. Push to the `angular-portfolio` branch of the `in` repository.
